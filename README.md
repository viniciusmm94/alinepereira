# Aline Pereira — Portfólio Jornalístico

Portfólio editorial em Next.js, preparado para deploy na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Publicar na Vercel

1. Envie a pasta para um repositório no GitHub.
2. Importe o repositório na Vercel.
3. A Vercel detectará o Next.js automaticamente.
4. Faça o deploy.

Todos os conteúdos ainda não fornecidos estão marcados como `XXXXXXXXXXX`.
